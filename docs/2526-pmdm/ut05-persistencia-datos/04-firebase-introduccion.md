Firebase es una plataforma de desarrollo de Google que ofrece servicios en la nube para facilitar la creación de aplicaciones de alta calidad.

### ¿Qué trataremos?
- **¿Qué es un MBaaS?**: Ventajas de no tener que gestionar un backend propio.
- **Servicios Principales**: Resumen de Auth, Firestore, Analytics y Cloud Messaging.
- **Configuración Inicial**: Registro en la consola, archivo `google-services.json` y dependencias del SDK.
- **Diferencia entre SQL y NoSQL**: Entendiendo el modelo de datos orientado a documentos.
