Firestore es la base de datos flexible y escalable de Firebase para el desarrollo de aplicaciones móviles y web.

### Contenido del Tutorial
- **Colecciones y Documentos**: Cómo estructurar la información.
- **CRUD en Firestore**: Añadir, leer, actualizar y eliminar datos en la nube.
- **Real-time Updates**: Uso de `addSnapshotListener` para actualizar la UI automáticamente cuando cambian los datos en el servidor.
- **Reglas de Seguridad**: Conceptos básicos para proteger los datos de acceso no autorizado.
