# 📱 Introducción al Desarrollo Android

¡Bienvenido al módulo de **Desarrollo de Aplicaciones Móviles**! En este espacio exploraremos el fascinante ecosistema de Android, aprendiendo a construir aplicaciones modernas, eficientes y visualmente atractivas.

Android no es solo un sistema operativo; es una plataforma global que impulsa miles de millones de dispositivos en todo el mundo. A lo largo de este curso, pasaremos de los conceptos fundamentales a la creación de aplicaciones funcionales listas para el usuario final.

## 🎯 Objetivos del Módulo

Al finalizar este módulo, serás capaz de:

*   **Configurar** un entorno de desarrollo profesional con Android Studio.
*   **Diseñar** interfaces de usuario dinámicas y adaptables.
*   **Comprender** el ciclo de vida de una aplicación y sus componentes esenciales.
*   **Implementar** lógica de negocio robusta utilizando **Kotlin**.
*   **Consumir** datos de fuentes externas y persistir información localmente.

## 🛠️ Herramientas de Trabajo

Utilizaremos las tecnologías más modernas y recomendadas por Google:

1.  **Android Studio:** Nuestro IDE principal (Koala/Ladybug o versión más reciente).
2.  **Kotlin:** El lenguaje de programación moderno y conciso para Android.
3.  **Jetpack Compose:** El kit de herramientas moderno para construir interfaces de usuario nativas.

## 📚 Estructura del Curso

El contenido está organizado de forma progresiva:

*   **Unidad 1:** Configuración y "Hola Mundo".
*   **Unidad 2:** Layouts y Diseño de Interfaces.
*   **Unidad 3:** Navegación y Arquitectura (MVVM).
*   **Unidad 4:** Gestión de Datos y APIs.
